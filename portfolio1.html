Portfolio 1: Automobile Fuel Economy

About the Data

This project explores fuel economy data for automobiles. The dataset contains both categorical and numerical variables. For these visualizations, I examined the relationship between drive type and average combined miles per gallon (MPG).

The question explored in all four visualizations is: How does average combined fuel economy differ by drive type?

Figure 1: Basic Bar Chart

This basic bar chart compares average combined fuel economy across four drive types. Drive type is represented on the x-axis and average combined MPG is represented on the y-axis. The height of each bar makes it easy to compare fuel efficiency across the four categories.

Figure 2: Sorted Horizontal Bar Chart

For the second visualization, I changed the bars from vertical to horizontal and sorted the categories from highest to lowest average MPG. The horizontal layout makes the drive-type labels easier to read, while sorting makes the ranking of the categories immediately visible.

Figure 3: Dot Plot

The third visualization replaces the bars with points. The position of each point along the x-axis communicates average MPG while using less visual space than the bar charts. This creates a simpler view that emphasizes the relative positions of the four values.

Figure 4: Bar Chart with Color Encoding

The final visualization uses sorted horizontal bars and adds a sequential color scale. Darker colors represent higher average MPG, providing an additional visual cue for the same numerical variable. Bar length remains the primary way to compare the values, while color reinforces the differences.
